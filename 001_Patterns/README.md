# 🔄 Update Guide

Whenever I solve a new pattern problem:

1. Add the solution to the appropriate `ExampleXX.java` file.
2. Add the problem to the corresponding **Example** section.
3. Continue the global problem number.
4. Add the problem to the **Problem Index**.
5. Update the **Progress** count.

If a new problem is added to `Example3.java`:
